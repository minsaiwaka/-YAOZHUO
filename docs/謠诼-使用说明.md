# 謠诼 · 使用说明

## 启动

使用 Node.js 24，在项目目录运行 `npm ci`，然后运行 `npm run dev:desktop`。Windows 与 macOS 使用相同的界面流程。`npm run dev` 可打开本地浏览器预览。

第一次使用可先选择虚构演示档案。演示人物、聊天和图片均为虚构内容。

## 1. 接入资料

点击“读取本机微信资料”，再点击“自动识别并填充”。多账号时先选择本次读取的账号；微信应已登录，应用与微信应使用同一系统账户。

数据库密钥先经过数据库页验证。图片 AES / XOR 参数另行从对应账号的本机保存配置或账号目录中的 `image_keys.json`、`image_key.json`、`key_info.json` 尝试读取，再用本地 DAT 图片样本核验；缺少 XOR 时可从一致的 PNG / JPEG 文件尾推导。只有通过验证的参数才自动填入。扫描有数量和时间上限，无法识别时可展开高级设置手动填写。

图片密钥不能替代数据库密钥。图片参数验证失败不阻止读取文字、联系人与会话；没有可验证的图片候选时不会凭空生成密钥。系统可能限制自动获取，界面会显示原因。

确认连接后读取联系人与会话，选择所需会话，再载入消息。默认读取全部可识别记录；若设置上限、取消或存在失败分库，资料范围会标为不完整。

也可导入支持的聊天 JSON 或之前保存的线索板 JSON。导入资料不会自动取得本机图片访问权限。

## 2. 选择中心人物

搜索姓名、备注、缩写或账号标识，点击人物。侧边栏上方显示当前整理对象。人物较多时可以翻页；画布上的人物也可双击设为中心。

## 3. 设置称呼

核对自动生成的姓名、备注和拼音首字母，补充外号与旧称呼，点击“更新称呼并重新检索”。例如：王小明、wxm、小明、明哥。

同名和缩写只是候选线索；多音字、代称或未登记的外号可能漏检，需要结合原文核实。

## 4. 筛查线索

- “完整线索”：逐项列出全部相关人物与群、关系、原文、媒体记录和手动素材，支持搜索与分页。
- “提及与话题”：查看各会话提及排行、高频话题和称呼命中原文。
- “记忆时间线”：查看相关消息，点击打开完整原文与相邻上下文，可釘选或排除无关消息。
- 日期范围及人工排除影响分析与报告；画布关键词、关系开关和仅看釘选仅影响对应视图。

相关记录包括直接会话、中心人物发言、称呼命中，以及同一会话中相距 15 分钟以内的相邻一条上下文。媒体列表按文件标识合并计数，使用当前人物的相关记录范围。

## 5. 编排线索板

添加便签或本地图片后，素材默认与中心人物连接。点击卡片底部“已连中心 / 连到中心”可取消或恢复，拖动时线段同步移动。手动连线使用点线，并标为人工线索，不计入自动关系强度。

拖动人物或素材标题移动，拖动右下角调整素材大小。素材标题和尺寸按钮也支持方向键微调；Shift 加大步长。滚轮缩放，空白处拖动画布。“中心”聚焦当前人物，“全部”适配所有人物和素材，“整理”重排人物。

自动关系线按消息依据信息量以对数尺度加粗，极端高频有上限。群聊成员线只计该成员发言，不拿全群消息数充当个人联系强度。线宽不代表亲密程度、身份确认或未见的私下关系。

“人物图鉴”可查看 200 款原创像素人物。默认按人物标识分配，也可点击人物卷宗照片或右侧“编辑人物档案 / 更换照片”，按编号与造型搜索并自行选择。照片仅作装饰。

## 6. 统计、卷宗与保存

“互动统计”和“人物卷宗”提供三个范围：

| 范围 | 内容 |
| --- | --- |
| 全部相关记录 | 私聊与群聊相关记录之和；报告同时列出三种统计 |
| 私聊相关记录 | 与中心的私聊，以及其他私聊中命中或相邻的相关记录 |
| 群聊相关记录 | 群内中心发言、提及和相关上下文，不等同于全群历史 |

每个范围包含消息数、会话数、发送比例、消息类型、活跃日、小时分布、高频话题和会话总计。中心人物就是本机账号时，发言只计入“中心人物”一次。时间按当前设备时区展示，报告原文时间使用 UTC。

HTML / Markdown 导出包含所选范围的完整原文与统计。卷宗预览最多显示前 30,000 字元，导出不受预览长度限制。

人物卷宗以档案卡展示像素照片、姓名、标识、称呼、常用语、偏好和说明。点击“编辑档案与照片”可填写资料、添加最多 20 个自定义栏；人工显示名不会改变原联系人姓名或检索称呼。人工资料与 AI 草稿分开标注；可将 AI 常用语与偏好复制到空白栏后继续编辑。HTML 内嵌像素照片，可离线打印。

JSON 始终保存全部已载入资料、人物档案与像素照片选择、可恢复的排除与日期设置、人物位置、图片、便签和手动连线，可再次导入继续整理。本地草稿自动保存；跨设备或长期归档建议导出 JSON。

最后一步可配置外接 AI，选择“全部相关聊天”“指定会话”或“指定消息”。支持搜索、限定会话、分页与跨页勾选，界面显示实际会话数和消息数。全部仅指当前已载入、通过日期及排除筛选的相关消息；指定会话也只包含其中的相关消息。未选消息不会发送，不自动补入未选上下文。人工备注与便签默认不发送，可单独勾选；人物档案的人工资料不会自动送入 AI。

修改范围或服务后需重新确认。AI 归纳本人自述、重复线索、他人描述、可能偏好和常用表达，附原文标识并保留不确定性。总结及导出记录实际选取范围；部分聊天不代表全部记录。单独私聊或群聊报告不会混入整体综述。未配置 AI 也可使用本地分析与报告。

## 07. 帮助

帮助独立于前六步，读取或 AI 生成过程中也可打开，当前连接与设置会保留。可搜索共同好友、连线、WAL、图片和保存等说明；人物图鉴提供全部 200 款分页预览与总览图。

## 读取和媒体问题

读取器只处理数据库副本，验证加密页及 WAL，合并可验证的已提交记录。正常检查点后的旧代际 WAL 尾部会被忽略；真正的校验损坏仍会报错或标为不完整。文件变化过快时可暂停收发后重试，切勿手动删除 WAL。

图片支持常见本地图片、旧 XOR DAT 和参数匹配的 AES / XOR DAT。WXGF、实况、视频和语音专用解码未全部内置，不能保证这些媒体可播放。找不到本地文件时可先在微信中下载，或手动添加图片。

密钥与 AI API Key 不写入档案。报告和 JSON 包含原文及图片，请自行保管。当前能力只涉及本机账号可见、已载入的记录。
